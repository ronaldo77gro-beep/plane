# БЛАЙНД — сайт клуба спортивного покера

Статический сайт (GitHub Pages) + база данных и аккаунты в Supabase.

## Что умеет

**Игроки**
- регистрация и вход по email, восстановление пароля;
- личный кабинет: статистика, брони, история турниров, редактирование профиля, смена пароля;
- расписание турниров, бронирование места в один клик, отмена брони;
- лист ожидания: если мест нет — игрок встаёт в очередь и автоматически записывается, когда место освобождается;
- **Топ месяца**: рейтинг за любой месяц и за всё время, пьедестал, публичные профили игроков.

**Крупье** (роль `dealer`)
- создание и редактирование турниров, копирование турнира на следующую неделю;
- управление турниром: открыть/закрыть запись, начать, завершить;
- добавление игроков (по нику или гостей без аккаунта), отметка «пришёл», случайная рассадка по столам;
- ребаи, аддоны, нокауты, кнопка «Вылет» (место ставится автоматически), призы;
- автоматический расчёт призового фонда, фишек в игре и среднего стека;
- завершение турнира с автоматическим начислением очков рейтинга;
- таймер блайндов для каждого турнира: экран для TV и пульт с телефона.

**Администратор** (роль `admin`) — всё, что может крупье, плюс:
- назначение ролей (игрок / крупье / администратор), блокировка игроков;
- удаление турниров; просмотр контактов игроков.

## Запуск (один раз)

1. **База данных.** Откройте проект в [Supabase](https://supabase.com/dashboard) → **SQL Editor** → **New query**,
   вставьте целиком содержимое `supabase/schema.sql` и нажмите **Run**. Скрипт можно запускать повторно — данные не удаляются.
   Если в проекте уже были таблицы `profiles`, `tournaments`, `registrations` и т.п. другого формата, скрипт не удаляет их,
   а переносит вместе с данными в отдельную схему `legacy_<дата_время>` (видна в Table Editor в списке схем).
2. **Подтверждение email.** Supabase → **Authentication → Sign In / Providers → Email**:
   - проще всего выключить **Confirm email** — игроки входят сразу после регистрации;
   - если оставить включённым, встроенная почта Supabase отправляет всего несколько писем в час — подключите свой SMTP
     (**Authentication → Emails → SMTP Settings**).
3. **Адрес сайта.** Supabase → **Authentication → URL Configuration**: в **Site URL** и **Redirect URLs** укажите адрес сайта,
   например `https://ronaldo77gro-beep.github.io/plane/` — нужен для ссылок из писем (подтверждение, восстановление пароля).
4. **Хостинг.** GitHub → репозиторий → **Settings → Pages** → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
5. **Первый администратор.** Первый зарегистрированный на сайте пользователь автоматически становится администратором.
   Поэтому зарегистрируйтесь первым сами. Назначить администратора вручную (SQL Editor):
   ```sql
   update public.profiles set role = 'admin' where nickname = 'ВашНик';
   ```
   Остальных крупье и администраторов назначайте на сайте: **Управление → Игроки**.

## Как считаются очки рейтинга

`очки = 10 × √N ÷ √место × коэффициент`, где N — число участников, коэффициент задаётся в настройках турнира.
Очки получает каждый участник рейтингового турнира. Топ месяца — сумма очков за календарный месяц.

## Таймер

- На странице управления турниром есть кнопки **«Таймер на TV»** и **«Пульт таймера»**.
- Экран TV открывается без входа; пульт работает только у вошедших крупье и администраторов.
- `timer.html` без параметров — общий таймер клуба (как раньше).
